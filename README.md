# Customer Churn Prediction

## Project Overview
This project focuses on predicting customer churn using Python and Machine Learning.

## Objective
The objective is to identify customers who are likely to leave a service by analyzing customer-related data and building a machine learning model.

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Machine Learning
- Data Analysis
- Data Visualization

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Preparation
5. Machine Learning Model Development
6. Model Evaluation
7. Customer Churn Prediction

## Project Files
- `My project.html` – Python/ML project notebook export
- `Machine Learning.html` – Machine Learning project notebook export

## Results
The project demonstrates the use of machine learning techniques for customer churn prediction.
